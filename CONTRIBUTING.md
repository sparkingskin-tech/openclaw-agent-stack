# Contributing

Thanks for your interest in contributing.

## Ways to Contribute

- Add new agent roles and agent templates
- Add workflow templates (n8n, Telegram, etc.)
- Improve examples and documentation
- Fix bugs in scripts or shell tooling

## Pull Request Guidelines

1. Keep changes scoped and easy to review.
2. Add or update documentation with code changes.
3. Test scripts locally before opening a PR.
4. For major architecture changes, open an issue first.

## Code Style

- Prefer clear naming and small functions.
- Keep examples runnable and documented.
- Preserve backward compatibility for existing script commands when possible.
