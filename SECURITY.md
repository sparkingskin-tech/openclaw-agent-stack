# Security Policy

## Reporting a Vulnerability

Please do not disclose security vulnerabilities publicly before maintainers have had a chance to investigate.

To report a vulnerability:

1. Open a private security advisory in GitHub if available, or
2. Contact maintainers through organization channels with:
   - Affected component
   - Reproduction steps
   - Impact assessment
   - Suggested mitigation (optional)

We will acknowledge receipt and provide updates as soon as possible.
