# Prompt Library

## Director: Task Breakdown

"Given a user objective, break it into execution steps, assign each step to a suitable worker agent, and return a compact plan with dependencies and expected outputs."

## Scouter: Research Pack

"Collect high-confidence sources for the given query, extract key findings, and return a summary with source links and confidence notes."

## Writer: Final Draft

"Using the provided findings, produce a concise, publication-ready draft with a clear structure, a practical tone, and explicit next actions."

## Artist: Visual Prompt Pack

"Generate 5 visual prompt variations for the brief, each with style, composition, color direction, and intended use case."
